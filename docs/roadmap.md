# Roadmap

Stewards publish goals here. The community builds against them. See [ADR 0001](adr/0001-open-source-community-model.md).

## Now

- Public repo, Apache-2.0 licence, contribution paths (this milestone).
- Scoped issues for contributions, bugs, and data-source proposals.

## Next

- Document accepted public data sources and provenance rules (no dumps in-repo).
- Define evaluation: what “understands Tunisian Derja” means in practice.
- Land scaffolding for data processing and training only after review.

## Later

- Community-trained model artefacts published with licence and eval notes.
- Instruction data and alignment work, still under Apache-2.0 and DCO.
